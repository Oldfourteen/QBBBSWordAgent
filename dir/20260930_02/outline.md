# Go语言程序设计学习期末报告

## 课程学习背景与整体目标

- 说明本学期开设 Go 语言课程的原因，以及这门语言在当前后端服务、命令行工具和云原生开发中的常见用途。
- 交代报告的写作范围：只总结课程中实际练习过的语法、示例和作业，不虚构项目成果、性能数据或调研结论。

### Go语言的特点与适用场景

- 从静态类型、编译执行、并发支持和部署方式几个方面说明 Go 的基本特点，并与课程中接触过的其它语言做简单对比。
- 结合课堂示例和课后练习，说明在什么情况下用 Go 写小工具或服务比其它写法更省事，也说明它的不足。

### 本学期学习目标与内容范围

- 列出本学期的学习目标：掌握基础语法、能独立读懂并修改完整的程序、学会查官方文档和看懂编译报错。
- 说明报告覆盖的内容范围与先后顺序，并如实交代自己在基础薄弱处遇到的困难。

## 基础语法与数据类型

- 梳理程序的基本结构、包声明、导入方式和语句书写规则，说明 Go 对格式统一的要求以及 gofmt 的作用。
- 说明基本数据类型、运算符与表达式，以及输入输出函数的常见用法。

### 变量、常量与基本类型

- 说明 var 声明与短变量声明的区别、常量与 iota 的用法，以及类型推断在什么时候会让代码更难读。
- 结合课后练习中的编译错误，说明类型转换必须显式书写、整数与浮点混算、未使用变量等问题。

### 数组、切片与映射

- 说明数组与切片在长度、传递方式上的差别，切片的追加、截取与扩容过程，以及底层数组共享可能带来的问题。
- 说明映射的建立、增删改查与遍历，键存在性判断的写法，以及在并发场景下直接读写映射的风险。

## 流程控制与函数

- 说明用条件判断和循环组织程序逻辑的基本写法，比较不同写法在可读性上的取舍。
- 记录做过的典型练习，说明解题思路、调试过程以及从运行结果与预期不一致中发现问题的方法。

### 条件与循环结构

- 说明 if、switch 的写法与各自适用场合，for 的几种形式以及 range 遍历时的常见误区。
- 通过求和、判断素数、打印乘法表等练习，说明循环边界、变量作用域和循环变量捕获引起的问题。

### 函数、多返回值与错误处理

- 说明函数定义、参数传递、匿名函数、闭包与 defer 的用法，以及多返回值带来的写法变化。
- 说明 Go 用返回值传递错误的约定、errors 包的简单使用方式和 panic 与 recover 的适用边界。

## 结构体、接口与并发编程

- 说明如何用结构体和方法把数据与操作放在一起，理解这样组织代码对维护的帮助。
- 初步理解接口与并发两个较难的部分，只写自己真正跑通过的内容，不夸大掌握程度。

### 结构体与方法的组织方式

- 说明结构体定义、字段导出规则、值接收者与指针接收者的区别，以及嵌入结构体的基本用法。
- 通过一个简单例子（如学生信息或商品记录）说明对象创建、字段访问与方法调用的过程。

### Goroutine 与 Channel 的初步使用

- 说明 goroutine 的启动方式、WaitGroup 等待结束的写法，以及主程序提前退出导致任务未完成的原因。
- 说明 channel 的发送接收、无缓冲与带缓冲的区别、关闭与遍历的写法，并说明自己对死锁问题的理解程度。
